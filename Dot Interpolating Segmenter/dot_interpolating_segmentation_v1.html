Appended to both exported filenames — e.g. photo_segmented_door.png & photo_blue_door.png. Useful for tracing several distinct objects on the same image: give each one a different label before exporting it.
How to use: click anywhere on the image to drop dots one after another, tracing along the boundary you want to segment. Click Finish line → once you have at least 2 dots to end an open line, or click the first dot again (once you have at least 3 dots) to close the shape into a loop. Use the zoom controls (or Ctrl/⌘ + scroll) to get closer to edges while placing or adjusting dots; scroll or drag the scrollbars to pan around when zoomed in. Drag any handle to nudge the line — the rendered/exported line is a smooth curve through the handles, not a straight-line polygon, so it should follow tight bends cleanly. Double-click on the line to insert a new handle at that spot; right-click a handle to delete it. When you're happy with the line, optionally set a label above, then export the two output images. Filenames automatically match your input file name, with _segmented and _blue suffixes (plus your label, if set). To trace a second, independent object on the same image: export the current line, click Start over, change the label, and trace the next one — each export gets its own distinct filenames.
